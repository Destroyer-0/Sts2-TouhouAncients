### 说明

- **专有名词**：`全人类的绯想天` = `Heaven of Scarlet Perception for All Humankind`（`ALL_CREATION_HISOU.title`）；`极限火花` = `Master Spark`；`异蛇之眼` = `Snecko Eye`（原版 `SNECKO_EYE`）；`异眼顶真的蛇瞳` = `Snecko's True Gaze`（`YIYANDINGZHEN.title`）；`幻灭三叉戟` = `Disillusion Trident`；`二重结界` = `Duplex Barrier`；`时间/魔法/罡气仆从` = `Time/Magic/Qi Minion`；`储君` = `The Regent`；`铁甲战士` = `The Ironclad`。
- **角色名**：`藤原妹红` = `Fujiwara no Mokou`；`蓬莱山辉夜` = `Kaguya Houraisan`；`封兽鵺` = `Nue Houjuu`；`古明地觉` = `Satori Komeiji`；`饕餮尤魔` = `Yuuma Toutetsu`。
- **Act 表述**：`二层/三层` 取原版 `Act 2` / `Act 3`（`PARADISE_DREAM` 已用 `Act 1`）。
- **`TOO_MUCH_SATORI` 分档**：铜/银/金分别对应 2/3/4 次。中文标题「二五仔 / 三五成群 / 姐姐增殖了！」是围绕「小五」（古明地觉的中文外号）的谐音梗，**英文无法直译**，改用一套自洽的「重复遭遇」梗：`Déjà Vu`（2 次，对读心者而言「似曾相识」）/ `Third Eye's the Charm`（3 次，谐音谚语 `Third time's the charm`，把 `time` 换成 `eye`「第三只眼」）/ `Sister Multiplied!`（4 次，直译）。
- **`ITALIAN_CANNON.title`「意大利炮」**：《亮剑》梗，英文直译 `Italian Cannon` 无意义，改译 `World Cracker`（歼星炮）——同为夸张的「大炮」意象，且与「极限火花」的高费爆发契合。
- **`MIRACLE_AGAIN.title`「奇迹再现」**：迪迦奥特曼主题曲梗，英文直译 `Miracle Again` 平淡，改译 `Miracle Reprise`（`reprise` = 再现/重演），保留「奇迹再次降临」的意味。
- **`REVENGE_FIRE_IRONCLAD.title`「代餐」**：中文网络语，指「得不到更好的 A，只能用稍差的 B 代替」（即备胎）。此处具体指妹红与铁甲战士都是**用火的战士**，对辉夜而言铁甲战士是妹红的「替身」。改译 `The Understudy`（戏剧术语：替角/替补演员），精确对应「顶替主角上场的替身」。
- **`SERVANT_FAMILY_PHOTO.title`「全家桶」**：取 `Family Bucket`（快餐全家桶）；「仆从」用 `Minion`，与三张卡名 `Time/Magic/Qi Minion` 一致。

jpn 与 eng 保持一致（旧工作流下以英文填充，现改为独立日语翻译）。

### 说明
- **`SCAMING_SCAMER.title`「FX战士」**：出自漫画《FX戦士くるみちゃん》，中文标题直接沿用该作标题。英文保留 `FX` 而不展开成 `Forex`，以维持与原作标题的逐字呼应（`FX` 本身即外汇的通用缩写，不影响理解）。
- **`HEALTH_CONSCIOUS.title`「注重养生」**：与类名 `HealthConscious` 同形，取 `Health Conscious`；「通过第一幕」取 `Clear Act 1`，`Act 1` 与原版 `LAVA_ROCK` / `UNDERDOCKS_EPOCH` 及仓库既有 `GENSOKYO_TRADITION`（`Act 2` / `Act 3`）一致。
- **`ULTRA_LUCKY.description`「耗能为0的牌」**：取 `zero-cost cards`，与 `LUCKY_RABBIT.description` 的 `those that cost [blue]0[/blue]` 同义；「幸运白兔」按规则 6 取 `cards.json` 的卡名 `Bare White Rabbit of Good Fortune`。
- **`SCAMING_SCAMER.description`「敲诈一笔」**：取 `Extort a fortune`；「依神姐妹」沿用 `YORIGAMI_SISTER_ANCIENT.fight.title` 的 `Yorigami Sisters`。
- **插入位置**：三条徽章按 zhs 的相对位置**集中**放在 `THREE_SNAKE` 与 `TOO_MUCH_SATORI` 之间，`zhs` / `eng` / `jpn` 三份文件键序完全一致。曾一度按 `eng/badges.json` 原有的字母序拆到三处插入，导致同一批内容在 diff 里东一块西一块，已改回对齐 zhs。
- jpn 与 eng 一致（旧工作流下以英文填充，现改为独立日语翻译）。
