## Part 1: 怪物类 (Monster Class)

### 1.1 怪物类

继承 `CustomMonsterModel`（来自 `BaseLib.Abstracts`）。

```csharp
using BaseLib.Abstracts;
using MegaCrit.Sts2.Core.Commands;
using MegaCrit.Sts2.Core.Entities.Ascension;
using MegaCrit.Sts2.Core.Entities.Creatures;
using MegaCrit.Sts2.Core.GameActions.Multiplayer;
using MegaCrit.Sts2.Core.Helpers;
using MegaCrit.Sts2.Core.Models.Powers;
using MegaCrit.Sts2.Core.MonsterMoves.Intents;
using MegaCrit.Sts2.Core.MonsterMoves.MonsterMoveStateMachine;

namespace YourMod.Scripts;

public class TestMonster : CustomMonsterModel
{
    // 怪物 ID 会由 BaseLib 自动处理为 {ModPrefix}:{ClassName}
    // 手动指定 ID 的方式见 BaseLib 文档
}
```

### 1.2 必需重写的属性

以下属性来自 `MonsterModel` 基类，必须重写：

| 属性 | 类型 | 说明 |
|------|------|------|
| `MinInitialHp` | `int` | 最小初始生命值 |
| `MaxInitialHp` | `int` | 最大初始生命值 |
| `GenerateMoveStateMachine()` | 方法 | 生成怪物的状态机（意图序列） |

### 1.3 Monster ID / 命名约定

- 键格式为 `{ModPrefix}-{MonsterName}`，如 `TEST-TEST_MONSTER`
- ID 由 BaseLib 根据 mod prefix + 类名自动生成

> 实际在 `monsters.json` 中使用的键名请以运行时的实际 ID 为准。

### 1.4 常用可重写属性

```csharp
// --- 生命值（必需）---
public override int MinInitialHp => 42;
public override int MaxInitialHp => 48;

// --- 进阶值调整 ---
// 使用 AscensionHelper 在不同进阶等级调整数值
public override int MinInitialHp =>
    AscensionHelper.GetValueIfAscension(AscensionLevel.ToughEnemies, 48, 42);
// 进阶 >= ToughEnemies 时 48，否则 42

// --- 音效 ---
public override string DeathSfx =>
    "event:/sfx/enemy/enemy_attacks/mymonster/mymonster_die";
public override string? HurtSfx => null; // 受伤音效（默认 null）
public override DamageSfxType TakeDamageSfxType => DamageSfxType.Slime;
// DamageSfxType: Armor / Slime 等，决定受击音效类型

// --- 其他 ---
public virtual string BestiaryAttackAnimId => "attack"; // 图鉴动画 ID
public override float DeathAnimLengthOverride => 0f; // 自定义死亡动画长度
public virtual bool ShouldFadeAfterDeath => true; // 死亡后是否淡出
public virtual bool IsHealthBarVisible => true; // 是否显示血条
public virtual float HpBarSizeReduction => 0f; // 血条缩减量
```

### 1.5 动画生成（可选）

如果怪物有 Spine 动画，重写 `GenerateAnimator`：

```csharp
public override CreatureAnimator GenerateAnimator(MegaSprite controller)
{
    AnimState idleState = new AnimState("idle_loop", isLooping: true);
    AnimState attackState = new AnimState("attack");
    AnimState hurtState = new AnimState("hurt");
    AnimState dieState = new AnimState("die");

    attackState.NextState = idleState;
    hurtState.NextState = idleState;

    CreatureAnimator animator = new CreatureAnimator(idleState, controller);
    animator.AddAnyState("Dead", dieState);
    animator.AddAnyState("Hit", hurtState);
    animator.AddAnyState("Attack", attackState);

    return animator;
}
```

### AnimatedSprite2D 动画衔接

`CustomMonsterModel.SetupCustomAnimationStates()` 只适用于 `SpineSprite`。本项目继承
`TouhouAncientMonster` 的 `AnimatedSprite2D` 怪物使用以下接口：

- 派生类只需重写 `InitialHp`；基类会令 `MinInitialHp` 与 `MaxInitialHp` 使用同一个值。
- `CreateCustomVisuals()` 默认加载 `res://scenes/creature_visuals/{类名}.tscn`。
- `TakeDamageSfxType` 由基类统一设置为 `DamageSfxType.Magic`。
- `CurrentLoopAnimation`：当前状态的常态循环动画；可根据阶段动态返回 `idle`、`spell` 等动画名。
- `GetNextAnimation(string finishedAnimation)`：非循环动画播放完成后的衔接规则；默认将 `hurt` 切回 `CurrentLoopAnimation`，返回 `null` 表示不自动切换。
- `ShouldPlayHurtAnimation`：控制游戏的 `Hit` 触发器是否播放 `hurt`；特殊状态可重写为 `false`。
- `HasAnimation`：是否拥有帧动画（`AnimatedSprite2D`），默认 `true`；纯静态贴图怪物（如奇幻蘑菇）重写为 `false` 以跳过所有 `AnimatedSprite2D` 处理。
- `PlayCurrentLoopAnimation()`：结束招式或切换状态时返回当前常态循环动画，避免硬编码 `idle`。

`TouhouAncientMonsterAnimationPatch` 会优先处理本项目帧动画怪物的 `Hit` 触发器，因此场景中即使还包含
`AnimationPlayer`，受击动画也会直接发送给 `AnimatedSprite2D`。

## Part 2: 怪物意图与行动 (Monster Moves / Intents)

### 2.1 MonsterMoveStateMachine 概述

每个怪物通过 `GenerateMoveStateMachine()` 方法返回一个 `MonsterMoveStateMachine`。该状态机由多个 `MonsterState` 组成：

- **`MoveState`**：一个具体的行动（攻击/防御/增益等）
- **`RandomBranchState`**：随机选择一个分支
- **`ConditionalBranchState`**：根据条件选择分支

### 2.2 Intent 类型

Intent 决定了怪物头顶显示的意图图标：

| Intent 类 | 图标类型 | 说明 |
|-----------|----------|------|
| `SingleAttackIntent(damage)` | 剑 | 单次攻击 |
| `MultiAttackIntent(damage, hits)` | 剑×N | 多次攻击 |
| `DefendIntent()` | 盾 | 防御/格挡 |
| `BuffIntent()` | 增益 | 给自己加增益 |
| `DebuffIntent()` | 减益 | 给玩家上负面效果 |
| `DeathBlowIntent(damage)` | 处决 | 致命一击 |

一个 `MoveState` 可以有多个 Intent（如同时攻击并格挡）。

### 2.3 简单攻击怪物示例

```csharp
protected override MonsterMoveStateMachine GenerateMoveStateMachine()
{
    List<MonsterState> states = new List<MonsterState>();

    // 定义一个攻击意图：伤害 10
    MoveState attackMove = new MoveState(
        "BASIC_ATTACK",           // 意图 ID，对应本地化键
        BasicAttackMove,          // 执行方法
        new SingleAttackIntent(10) // 意图显示
    );
    // 攻击后再次执行同一个意图（循环）
    attackMove.FollowUpState = attackMove;

    states.Add(attackMove);
    return new MonsterMoveStateMachine(states, attackMove);
}

// 攻击执行方法
private async Task BasicAttackMove(IReadOnlyList<Creature> targets)
{
    await DamageCmd.Attack(10)
        .FromMonster(this)
        .WithAttackerFx(null, AttackSfx)
        .WithHitFx("vfx/vfx_attack_slash")
        .Execute(null);
}
```

### 2.4 多意图 + 随机分支示例

```csharp
protected override MonsterMoveStateMachine GenerateMoveStateMachine()
{
    List<MonsterState> states = new List<MonsterState>();

    MoveState attackMove = new MoveState("ATTACK", AttackMove,
        new SingleAttackIntent(AttackDamage));
    MoveState defendMove = new MoveState("DEFEND", DefendMove,
        new DefendIntent());
    MoveState buffMove = new MoveState("BUFF", BuffMove,
        new BuffIntent());

    // 随机分支：随机选择一个意图，不能连续重复
    RandomBranchState randomBranch = new RandomBranchState("RANDOM");
    randomBranch.AddBranch(attackMove, MoveRepeatType.CannotRepeat);
    randomBranch.AddBranch(defendMove, MoveRepeatType.CannotRepeat);
    randomBranch.AddBranch(buffMove, MoveRepeatType.CannotRepeat);

    // 所有意图执行后回到随机分支
    attackMove.FollowUpState = randomBranch;
    defendMove.FollowUpState = randomBranch;
    buffMove.FollowUpState = randomBranch;

    states.Add(attackMove);
    states.Add(defendMove);
    states.Add(buffMove);
    states.Add(randomBranch);

    return new MonsterMoveStateMachine(states, randomBranch);
}
```

### 2.5 条件分支示例

根据战斗状态选择不同意图：

```csharp
// 条件分支：首次进入时根据条件选择
ConditionalBranchState initBranch = new ConditionalBranchState("INIT");

// 如果某个条件成立，执行 A；否则执行 B
initBranch.AddState(buffMove, () => NeedToBuff());
initBranch.AddState(attackMove); // 默认分支（无条件 = 始终成立）
```

### 2.6 DamageCmd 攻击指令详解

```csharp
// 基本单次攻击
await DamageCmd.Attack(10)                // 基础伤害值
    .FromMonster(this)                     // 攻击来源
    .Execute(null);                        // 目标（null = 玩家）

// 多段攻击
await DamageCmd.Attack(2)                  // 每段伤害
    .FromMonster(this)
    .WithHitCount(8)                       // 段数
    .Execute(null);

// 带特效和音效的攻击（禁止添加 WithAttackerAnim 动画）
await DamageCmd.Attack(15)
    .FromMonster(this)
    .WithAttackerFx(null, AttackSfx)       // 攻击方特效 & 音效
    .WithHitFx("vfx/vfx_attack_slash")     // 受击方特效
    .Execute(null);
```

### 2.7 其他常用指令

```csharp
// 获得格挡
await CreatureCmd.GainBlock(base.Creature, amount, ValueProp.Move, null);

// 施加能力（对玩家施放时必须传入 new ThrowingPlayerChoiceContext()）
await PowerCmd.Apply<StrengthPower>(new ThrowingPlayerChoiceContext(), base.Creature, amount, base.Creature, null);
await PowerCmd.Apply<FrailPower>(new ThrowingPlayerChoiceContext(), targets, amount, base.Creature, null);

// 显示对话
TalkCmd.Play(locString, base.Creature, VfxColor.Cyan);
```

### 2.8 对话 / Banter 文本

对话通过本地化系统加载。在意图执行时调用：

```csharp
private async Task ShowDialogueForMove(string moveId)
{
    // 从 monsters 表中获取该意图的所有 speakLine
    LocTable table = LocManager.Instance.GetTable("monsters");
    IEnumerable<LocString> lines = table.GetLocStringsWithPrefix(
        base.Id.Entry + ".moves." + moveId + ".speakLine");

    LocString locString = Rng.Chaotic.NextItem(lines);
    if (locString != null)
    {
        TalkCmd.Play(locString, base.Creature, VfxColor.Cyan);
        await Cmd.Wait(0.5f);
    }
}
```

## Part 3: 怪物场景 (tscn Scene)

### 3.1 节点结构

#### BaseLib 版本

```
TestMonster (Node2D)
├── Visuals (Node2D) %
├── Bounds (Control) %
├── IntentPos (Marker2D) %
└── CenterPos (Marker2D) %
```

### 3.2 节点说明

| 节点名 | 类型 | 说明 |
|--------|------|------|
| `Visuals` | `Node2D` / `Sprite2D` | 怪物的视觉表现（精灵图/Spine 动画） |
| `Bounds` | `Control` | 怪物的碰撞盒大小，影响血条长度 |
| `IntentPos` | `Marker2D` | 意图图标显示位置 |
| `CenterPos` | `Marker2D` | 怪物中心位置 |

> **重要**：所有子节点必须右键 → 勾选「作为唯一名称访问」（Access as Unique Name），编辑器中会显示 `%` 标记。节点名称**不可修改**。

### 3.3 位置说明

- 怪物显示在 **x 轴上方**（Y 坐标为负值，向上）
- `Bounds` 的大小决定血条长度，如果觉得血条太短，调整 `Bounds` 的尺寸

## Part 4: 本地化 (Localization)

### 4.1 monsters.json

文件路径：`{modId}/localization/{Language}/monsters.json`

```json
{
  "TEST-TEST_MONSTER.name": "戈多",
  "TEST-TEST_MONSTER.moves.BASIC_ATTACK.title": "基础攻击",
  "TEST-TEST_MONSTER.moves.BASIC_ATTACK.banter": "[jitter]接下这招！[/jitter]",
  "TEST-TEST_MONSTER.moves.HEAVY_ATTACK.title": "重击"
}
```

### 4.2 monsters.json 键名规范

| 键名模式 | 说明 | 示例 |
|----------|------|------|
| `{MONSTER_KEY}.name` | 怪物显示名称 | `"AXEBOT.name": "巨斧机器人"` |
| `{MONSTER_KEY}.moves.{MOVE_KEY}.title` | 意图显示名称 | `"AXEBOT.moves.SHARPEN.title": "打磨"` |
| `{MONSTER_KEY}.moves.{MOVE_KEY}.banter` | 意图对话文本（单行） | `"CALCIFIED_CULTIST.moves.INCANTATION.banter": "[jitter]我们的力量无人能及！[/jitter]"` |
| `{MONSTER_KEY}.moves.{MOVE_KEY}.speakLine1` | 意图对话文本（多行，随机选取） | `"FAKE_MERCHANT_MONSTER.moves.SWIPE.speakLine1": "来打啊！"` |
| `{MONSTER_KEY}.moves.{MOVE_KEY}.speakLine2` | 意图对话文本第 2 行 | 同上，编号递增 |

> **注意**：
> - `banter` 和 `speakLine` 是可选的，如果意图中没有使用对话就可以不填。
> - `speakLine` 支持多行（`speakLine1`, `speakLine2`, ...），运行时会随机选取一行显示。
> - 可以使用富文本标记如 `[jitter]`, `[sine]`, `[gold]`, `[red]` 等。

### 4.3 encounters.json

文件路径：`{modId}/localization/{Language}/encounters.json`

```json
{
  "TEST-TEST_ENCOUNTER.title": "一只戈多",
  "TEST-TEST_ENCOUNTER.loss": "{character}被[gold]{encounter}[/gold]折磨而死。",
  "TEST-TEST_MULTI_ENCOUNTER.title": "很多戈多",
  "TEST-TEST_MULTI_ENCOUNTER.loss": "{character}被[gold]{encounter}[/gold]的一堆新版本淹没。"
}
```

### 4.4 encounters.json 键名规范

| 键名模式 | 说明 | 模板变量 |
|----------|------|----------|
| `{ENCOUNTER_KEY}.title` | 遭遇名称（地图节点上显示） | — |
| `{ENCOUNTER_KEY}.loss` | 玩家被击败文本 | `{character}` = 角色名，`{encounter}` = 遭遇名 |

## Part 5: 遭遇 (Encounter)

### 5.1 简单遭遇（单怪物）

```csharp
using System.Collections.Generic;
using BaseLib.Abstracts;
using BaseLib.Extensions;
using MegaCrit.Sts2.Core.Models;
using MegaCrit.Sts2.Core.Rooms;

namespace YourMod.Scripts;

public class TestEncounter : CustomEncounterModel
{
    // 所有可能出现的怪物
    public override IEnumerable<MonsterModel> AllPossibleMonsters =>
        [ModelDb.Monster<TestMonster>()];

    // 在哪些幕出现（ActNumber() == 1 表示只在第一幕）
    public override bool IsValidForAct(ActModel act) =>
        act.ActNumber() == 1;

    // 必须重写：返回实际刷出的怪物及 Marker2D 位置
    protected override IReadOnlyList<(MonsterModel, string?)> GenerateMonsters() =>
        [(ModelDb.Monster<TestMonster>().ToMutable(), null)];

    // 是否为弱怪物池遭遇
    public override bool IsWeak => false;

    public TestEncounter() : base(RoomType.Monster)
    {
    }
}
```

### 5.2 多怪物遭遇

```csharp

public class TestMultiEncounter : CustomEncounterModel

    protected override IReadOnlyList<(MonsterModel, string?)> GenerateMonsters() =>
    [
        (ModelDb.Monster<TestMonster>().ToMutable(), "first"),
        (ModelDb.Monster<TestMonster>().ToMutable(), "second"),
    ];

    // 是否为弱怪物池遭遇
    public override bool IsWeak => false;

    public TestMultiEncounter() : base(RoomType.Monster)
    {
    }
}
```

### 5.3 遭遇场景 (tscn)

多怪物遭遇需要 tscn 场景文件，用 `Marker2D` 节点标记怪物刷新位置：

```
TestMultiEncounter (Node2D)
├── first (Marker2D)
├── second (Marker2D)
├── third (Marker2D)
├── fourth (Marker2D)
├── first2 (Marker2D)
├── second2 (Marker2D)
├── third2 (Marker2D)
└── fourth2 (Marker2D)
```

> Marker2D 的名称（`first`, `second`, ...）为系统保留名称，对应不同槽位。具体场景文件在 Godot 编辑器中创建即可。

### 5.4 EncounterModel 常用属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `AllPossibleMonsters` | `IEnumerable<MonsterModel>` | 此遭遇可能使用的所有怪物 |
| `GenerateMonsters()` | 方法 | **必须重写**，返回实际刷出的怪物及 Marker2D 位置 |
| `RoomType` | `RoomType` | 房间类型：`Monster` / `Elite` / `Boss` |
| `IsValidForAct(ActModel)` | 方法 | 控制在哪些幕出现 |
| `IsWeak` | `bool` | 是否为弱怪物池 |
| `IsDebugEncounter` | `bool` | 是否仅为调试遭遇 |
| `ShouldGiveRewards` | `bool` | 是否给予奖励 |
| `MinGoldReward` / `MaxGoldReward` | `int` | 金币奖励范围 |
| `CustomBgm` | `string` | 自定义背景音乐 |
| `AmbientSfx` | `string` | 环境音效 |

### 6.2 怪物类 (GoblinScout.cs)

```csharp
using System.Collections.Generic;
using System.Threading.Tasks;
using BaseLib.Abstracts;
using MegaCrit.Sts2.Core.Commands;
using MegaCrit.Sts2.Core.Entities.Ascension;
using MegaCrit.Sts2.Core.Entities.Creatures;
using MegaCrit.Sts2.Core.GameActions.Multiplayer;
using MegaCrit.Sts2.Core.Helpers;
using MegaCrit.Sts2.Core.MonsterMoves.Intents;
using MegaCrit.Sts2.Core.MonsterMoves.MonsterMoveStateMachine;

namespace YourMod.Scripts.Monsters;

public class GoblinScout : CustomMonsterModel
{
    // === 基础属性 ===
    public override int MinInitialHp =>
        AscensionHelper.GetValueIfAscension(AscensionLevel.ToughEnemies, 48, 42);
    public override int MaxInitialHp =>
        AscensionHelper.GetValueIfAscension(AscensionLevel.ToughEnemies, 52, 46);

    // === 伤害数值（随进阶变化）===
    private int StabDamage =>
        AscensionHelper.GetValueIfAscension(AscensionLevel.DeadlyEnemies, 14, 12);
    private int BlockAmount =>
        AscensionHelper.GetValueIfAscension(AscensionLevel.ToughEnemies, 7, 5);
    private int StrengthGain =>
        AscensionHelper.GetValueIfAscension(AscensionLevel.DeadlyEnemies, 3, 2);

    // === 音效 ===
    public override DamageSfxType TakeDamageSfxType => DamageSfxType.Slime;

    // === 状态机 ===
    protected override MonsterMoveStateMachine GenerateMoveStateMachine()
    {
        List<MonsterState> states = new List<MonsterState>();

        // 意图 1：攻击
        MoveState stabMove = new MoveState("STAB", StabMove,
            new SingleAttackIntent(StabDamage));

        // 意图 2：防御 + 攻击
        MoveState guardMove = new MoveState("GUARD", GuardMove,
            new SingleAttackIntent((int)(StabDamage * 0.6)),
            new DefendIntent());

        // 意图 3：增益
        MoveState rallyMove = new MoveState("RALLY", RallyMove,
            new BuffIntent());

        // 随机分支：前两个意图不能连续重复
        RandomBranchState randomBranch = new RandomBranchState("RANDOM");
        randomBranch.AddBranch(stabMove, MoveRepeatType.CannotRepeat);
        randomBranch.AddBranch(guardMove, MoveRepeatType.CannotRepeat);
        randomBranch.AddBranch(rallyMove, 1, MoveRepeatType.CannotRepeat);

        // 所有意图结束后回到随机分支
        stabMove.FollowUpState = randomBranch;
        guardMove.FollowUpState = randomBranch;
        rallyMove.FollowUpState = randomBranch;

        states.Add(stabMove);
        states.Add(guardMove);
        states.Add(rallyMove);
        states.Add(randomBranch);

        return new MonsterMoveStateMachine(states, randomBranch);
    }

    // === 行动方法 ===

    private async Task StabMove(IReadOnlyList<Creature> targets)
    {
        await DamageCmd.Attack(StabDamage)
            .FromMonster(this)
            .WithAttackerFx(null, AttackSfx)
            .WithHitFx("vfx/vfx_attack_slash")
            .Execute(null);
    }

    private async Task GuardMove(IReadOnlyList<Creature> targets)
    {
        await CreatureCmd.GainBlock(base.Creature, BlockAmount,
            ValueProp.Move, null);
        await DamageCmd.Attack((int)(StabDamage * 0.6))
            .FromMonster(this)
            .WithAttackerFx(null, AttackSfx)
            .WithHitFx("vfx/vfx_attack_slash")
            .Execute(null);
    }

    private async Task RallyMove(IReadOnlyList<Creature> targets)
    {
        await PowerCmd.Apply<StrengthPower>(new ThrowingPlayerChoiceContext(), base.Creature, StrengthGain,
            base.Creature, null);
    }
}
```

## 硬性约束 (Hard Constraints)

### 动画禁令
- **禁止添加任何动画相关代码**，包括：
  - `WithAttackerAnim(...)` — 攻击方动画
  - `CreatureCmd.TriggerAnim(...)` — 触发动画
- **不要直接删除**已有的动画代码，使用 `// TODO: 动画 - ` 前缀注释掉：
  ```csharp
  // TODO: 动画 - await CreatureCmd.TriggerAnim(base.Creature, "Cast", 0.6f);
  // TODO: 动画 - .WithAttackerAnim("Attack", 0.15f)
  ```
- 特效和音效（`WithAttackerFx`、`WithHitFx`、`AttackSfx`）可以保留

### PowerCmd.Apply 语法
- 对任意目标施放 Power 时，**必须**传入 `new ThrowingPlayerChoiceContext()` 作为第一个参数：
  ```csharp
  // 正确写法
  await PowerCmd.Apply<FrailPower>(new ThrowingPlayerChoiceContext(), targets, amount, base.Creature, null);
  await PowerCmd.Apply<StrengthPower>(new ThrowingPlayerChoiceContext(), base.Creature, amount, base.Creature, null);
  ```

### 禁止直接获取玩家引用
- **严禁**使用 `Player player = base.CombatState.Players[0];` 或其他索引方式获取玩家
- 必须使用 `targets`（Move 方法的 `IReadOnlyList<Creature> targets` 参数）或 `damageResult.Receiver`（`DamageCmd` 返回值）来获取目标生物

### AfterSideTurnStart / AfterSideTurnEnd
- 正确的签名：
  ```csharp
  public override async Task AfterSideTurnStart(CombatSide side, IReadOnlyList<Creature> participants, ICombatState combatState)
  public override async Task AfterSideTurnEnd(PlayerChoiceContext choiceContext, CombatSide side, IEnumerable<Creature> participants)
  ```
- **必须**包含参与者检查：
  ```csharp
  if (!participants.Contains(Owner))
  {
      return;
  }
  ```

### GenerateMonsters
- 遭遇类**必须**重写 `GenerateMonsters()`，不可遗漏
- 单怪物：`[(ModelDb.Monster<X>().ToMutable(), null)]`
- 多怪物：`[(ModelDb.Monster<A>().ToMutable(), "first"), (ModelDb.Monster<B>().ToMutable(), "second")]`
